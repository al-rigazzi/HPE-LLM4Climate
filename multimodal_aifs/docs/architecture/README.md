# Architecture Diagrams

This directory contains diagram generators and generated PDF diagrams.

## Files

- `create_aifs_architecture_diagram.py`
- `create_aifs_attention_detail.py`
- `aifs_multimodal_architecture_diagram.pdf`
- `aifs_cross_attention_detail.pdf`

## Generate Diagrams

```bash
cd multimodal_aifs/docs/architecture
python create_aifs_architecture_diagram.py
python create_aifs_attention_detail.py
```

## Outputs

- `aifs_multimodal_architecture_diagram.pdf`
- `aifs_cross_attention_detail.pdf`
